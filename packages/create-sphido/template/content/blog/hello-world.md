# Hello World

This is the first post. It demonstrates the `@sphido/hashtags` extender:
any #hashtag in the text is collected into `page.tags` and replaced with
a link — like #sphido and #blogging here.

Write Markdown, run `node index.js`, and the post shows up in `public/blog/`.

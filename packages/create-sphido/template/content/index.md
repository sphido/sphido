# Welcome to Sphido

This site was scaffolded with `npm create sphido` and is built by
[Sphido](https://sphido.cz) — a static site generator that is basically
just two functions: `getPages()` and `allPages()`.

Edit the Markdown files in the `content/` folder, then rebuild:

```shell
node index.js
```

The generated HTML lands in `public/`.

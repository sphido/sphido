# About

Pages are plain Markdown files with optional YAML front matter at the top.
The `title`, `description` and `date` fields above are read by the
`@sphido/frontmatter` extender and end up directly on the `page` object.

Add a new `.md` file anywhere under `content/` and it becomes a page.
Files starting with `_` are treated as drafts and skipped.
